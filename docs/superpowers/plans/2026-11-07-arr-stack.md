# \*arr Stack on firth Implementation Plan

> **Historical plan; do not run it.** It was written before implementation and is a script of live
> commands that no longer matches the final code (no `arr_enabled` flag, no restart handler,
> different vault files and key names, the Filebot/FlexGet tasks were done differently, and the
> stack gained Bazarr, autobrr, FlareSolverr and Tailscale Services). Read the role and the PR instead.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take the hand-managed `haugene/transmission-openvpn` compose project under Ansible, run it as `jellyfin`, and add Sonarr, Radarr, Prowlarr, Bazarr and Seerr, retiring FlexGet and `sync_or_swim`.

**Architecture:** New role `firth_media_stack` templates one compose file at `{{ docker_root }}/vpn` and runs it with `community.docker.docker_compose_v2` (same pattern as `firth_elasticsearch`). The \*arrs are behind a flag so the first apply is a no-behaviour-change takeover. Spec: `docs/superpowers/specs/2026-11-07-arr-stack-design.md`.

**Tech Stack:** Ansible, Docker Compose v2, `linuxserver/*` images, nginx.

**Repo rules that apply:** work on `feature/arr-stack` (never main); full playbook output goes to a file via `tee`, never `head`/`tail`; removed things need explicit `state: absent` tasks; reference facts as `ansible_facts['x']`; commits are emoji-prefixed and end with the Co-Authored-By line; PRs are drafts.

**Logs and secrets:** `--diff` prints whole templates. The compose file (OpenVPN credentials, handled with `diff: false`) and Filebot's `organise_media_downloads` (Discord webhook) contain secrets. Run `umask 077` before any `tee /tmp/...` log, never paste a diff of those files, and delete the logs when the task is done. Check a log with `grep -c` for secret markers rather than reading it.

**Verification model:** there are no unit tests for Ansible roles here. The checks are `ansible-lint` (a pre-commit hook), `ansible-playbook --check --diff`, `docker compose config`, and the live checks in each task.

```yaml
    - name: Template docker-compose.yml for the media stack
      ansible.builtin.template:
        src: docker-compose.yml.j2
        dest: "{{ firth_media_stack_dir }}/docker-compose.yml"
        owner: "{{ firth_media_stack_user }}"
        group: docker
        mode: "0640"

    - name: Start media stack
      community.docker.docker_compose_v2:
        project_src: "{{ firth_media_stack_dir }}"
        pull: always
        state: present
        recreate: auto

    - name: Debug media stack failure
      ansible.builtin.debug:
        var: ansible_failed_result

    - name: Abort media stack failure
      ansible.builtin.fail:
        msg: "Cannot continue: media stack setup failed."
```

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name requests.aqxs.net;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl proxy_protocol;
    listen [::]:443 ssl proxy_protocol;
    server_name requests.aqxs.net;

    include /etc/nginx/snippets/ssl/aqxs_ssl.conf;
    add_header X-WhyAmI seerr;
    add_header X-Content-Type-Options "nosniff";

        proxy_pass http://127.0.0.1:5055;

        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
```
